# context-packs

One-file briefs you paste into an agent and say: **do this.**

Each pack is a single, self-contained Markdown file. It carries only the context an agent
can't regenerate on its own — the key decision and the landmines — and nothing else. No
skills, no setup. Paste and go.

## Packs

- [github-cleanup](github-cleanup.md) — declutter a GitHub account without deleting anything.

## Why

Most of the value of a long working session is a handful of decisions and gotchas. This
repo ships just those, compressed into something the next agent can consume in a few
hundred tokens instead of an afternoon.
